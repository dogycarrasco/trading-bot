ℹ️ Cómo funciona

Estrategia actual: Multi-signal voting (5 capas). El bot evalúa 5 señales (Regime, Sentiment, Onchain, Trend, Setup) y solo compra si ≥3 de 5 votan +1. Vende por triple-barrier (ATR-based) o trailing stop.

📊 Backtest: antes de deployar, el sistema probó la estrategia con 18 años de datos históricos (2007-2026). Resultado: CAGR +11.33% vs SPY +8.58%, win rate semanal 44.9% vs SPY 14.6%.

🔄 Paper trading: simula trades con $500 virtuales. No usa dinero real. Cada 2 horas GitHub Actions ejecuta un ciclo: descarga precios → evalúa signals → compra/vende según estrategia → actualiza este dashboard.

🧠 Aprendizaje: el bot guarda el historial de trades cerrados. Con suficiente historia, entrena un meta-modelo (LightGBM) que filtra señales malas (conviction gating).

📈 Métricas clave:

  • Capital total: cash + valor de posiciones
  • P&L: ganancia/pérdida desde $500 inicial
  • Win rate semanal: % de semanas con retorno positivo
  • Max DD: máxima caída desde el pico (drawdown)
